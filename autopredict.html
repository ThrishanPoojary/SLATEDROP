01 / OVERVIEW

What is AutoPredict?

AutoPredict is a machine learning web application designed to estimate the resale price of used cars. Users enter vehicle information such as brand, manufacturing year, kilometres driven, fuel type, transmission and ownership. The trained machine learning model processes these details and returns an estimated price in Indian Rupees.

The project connects a web-based frontend to a Python backend through an API, allowing predictions to happen through a deployed online application.

02 / HOW IT WORKS

From input to prediction.

STEP 01

Vehicle Details

The user enters the car's specifications.

STEP 02

API Request

The frontend sends the information to FastAPI.

STEP 03

ML Processing

The trained Random Forest model processes the data.

STEP 04

Price Estimate

The predicted price is returned and displayed.

04 / MODEL

Machine learning engine.

Random Forest Regressor

A supervised machine learning algorithm that uses multiple decision trees to estimate used car prices.

Data preprocessing

Categorical features are transformed using OneHotEncoder, while numerical features are passed through the preprocessing pipeline.

Model evaluation

Evaluated using Mean Absolute Error, Root Mean Squared Error and the R² score.

Model deployment

The trained model is saved using Joblib and loaded by the FastAPI backend to serve predictions.

Model performance on the test dataset: R² score approximately 0.6051. Predictions are estimates, not guaranteed market prices. Actual resale value may differ depending on vehicle condition, location and market demand.
